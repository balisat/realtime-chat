# Real-Time Chat App

A chat interface with simulated live messaging. It is a single-file HTML/CSS/JavaScript web app — all of the markup, styles, and logic live in `index.html`.

## What it does

- Send and view messages in a chat interface
- Switch between chat rooms and follow each conversation
- See simulated live activity, including incoming replies and typing indicators
- Track who is online and view member presence

## How to run

- Open `index.html` in a browser — no build step or installation is required.
- Or serve the repository with GitHub Pages, where `index.html` is the entry page.
